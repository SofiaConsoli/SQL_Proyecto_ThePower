# SQL_Proyecto_ThePower
Proyecto del módulo de SQL del master de DataAnalyst, ThePowerEducation.

# Descripción del proyecto
El proyecto consiste en poner en práctica el conocimiento recogido en los módulos de contenido del proyecto y las clase teorico/prácticas impartidas durante el mismo. Para ello, se plantean enunciados  de diferente grado de dificultad que pretenden hacer un recorrido por todo el contenido. Además, se busca verificar el correcto uso de las herramientas utilizadas en el curso, como DBeaver y GitHub.

# Base de datos utilizada
Se utilizó una base de datos relacional, que simula el funcionamiento de un sistema de alquiler de películas.

# Pasos seguidos durante el proyecto

Los pasos que he seguido en el desarrollo del proyecto son los siguientes:
    1- Cargar BBDD en DBeaver: agregar nueva BBDD en postgres, establecerla por defecto, ir a 'Archivo', 'Buscar archivo denominado'y buscar el archivo de la BBDD descargada previamente.
    2- Desarrollo de los enunciados: crear un nuevo script, copiar y pegar los enunciados en el Script, utilizar doble guion alto para convertir los en comentarios, desarrollar cada enunciado. Dentro de este punto se puede detallar el paso a paso del desarrollo de los enunciados:
        1. Análisis del enunciado de cada ejercicio para entender qué información se solicitaba.
        2. Identificación de las tablas necesarias y sus relaciones.
        3. Elección del tipo de JOIN adecuado según el resultado esperado.
        4. Uso de funciones de agregación como COUNT, SUM y AVG cuando fue necesario.
        5. Aplicación de GROUP BY y HAVING para filtrar resultados agregados.
        6. Uso de subconsultas para resolver ejercicios más complejos.
        7. Revisión y simplificación de consultas para que fueran claras y eficientes.
        8. Construcción de tablas temporales

    3- Presentación del proyecto: crear un repositorio nuevo en GitHub Deskpot, guardar el script en la carpeta del repositorio, guardar el esquema de la BBDD, volver a GitHub y clickear en 'Push origin'.
    4- Modificar README: hacer un informe detallado del análisis junto con los pasos seguidos  en la cosntrucción del proyecto.

# Conclusiones

Este proyecto me permitió afianzar el uso de SQL para analizar datos reales, poniendo en práctica lo aprendido teóricamente durante el curso. Dentro de los aprendizajes más importantes se destacan:

- Simplificar las consultas a pesar de que se puedan desarrollar de diferentes formas para llegar al mismo resultado
- Hacer uso de la lógica y comprender la estructura del lenguaje
- Elegir correctamente el tipo de JOIN según el problema
- Diferenciar entre WHERE y HAVING
- Trabajar con subconsultas y funciones de ventana
- Interpretar correctamente los resultados obtenidos
